# bag-domains

Подписанный реестр доменов сервиса BAG: `bag-domains.json`.

- Формат: `{"payload": base64(JSON), "sig": base64(Ed25519(payload))}`.
- Приложения BAG проверяют подпись встроенным открытым ключом и принимают
  только реестр новее своего. Подделанный или старый файл игнорируется.
- Выпускает только `bag-domains` на сервере владельца, после его подтверждения.

Открытый ключ (Ed25519, base64): `eQ/Q93Zm+49X3lakfcOeVzMEbFfKUVYSTDDt5bg1cS0=`
